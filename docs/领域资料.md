# 领域资料：品质客诉与厂内异常（公开资料整理）

> 不用问人就能收集到的部分。来源标注规则：**[公开流程]** 来自 8D 标准方法的公开资料；**[GPT 调研]** 出处由 GPT 10-19 给出、Claude 未逐条核对原文；**[通用知识]** 制造业常识，用来写合成数据，不当作引用依据。等品质同事访谈后再校正。

## 1. 8D 流程和作品各部分的对应

| 8D 步骤 | 要做的事 | 作品里对应 |
|---|---|---|
| D0 准备 / 受理 | 登记问题，判断严重性，决定是否启动正式调查 | `get_complaint` 读原文 |
| D1 组队 | 指定负责人 | 不做（由人决定） |
| D2 问题描述 | 产品、批次、时间、数量、缺陷表现、判定标准 | `problem` 字段（问题整理） |
| D3 临时遏制 | 隔离、挑选、停发，覆盖在库、在途、客户现场 | `containment` 字段 |
| D4 原因分析 | 同时查**发生原因**（为什么会产生）和**流出原因**（为什么没拦住），提出假设并验证 | `hypotheses`，`kind` 区分两类 |
| D5 选择措施 | 针对原因提出永久措施，先验证有效性 | `reference_actions`（引用历史措施） |
| D6 实施并验证 | 用后续检验 / 生产结果验证效果 | `verified` 只能照抄历史案例的 `effective` |
| D7 防再发 | 更新控制计划、横向排查类似产品 | 路演可讲，作品暂不做 |
| D8 结案 | 评审、签署 | 人工审批，agent 只能写“可提交审批” |

来源：[公开流程] [ASQ：8D 方法](https://asq.org/quality-resources/eight-disciplines-8d)；[GPT 调研] [BSH 供应商 8D 指南](https://media3.bsh-group.com/Documents/Overview_ProblemSolving_with_8D_Method_EN.pdf)。

## 2. 调查时常查的记录

| 记录 | 回答什么问题 | 数据包里的对应 |
|---|---|---|
| 客诉原文、照片、退回样品 | 客户实际报告了什么，能否复现 | `complaints.json`、退回样品复检记录 |
| 图纸 / 规格 / 测量点 | 按哪个标准判不良，双方测量方法是否一致 | 检验记录的 note（如 A 点 vs 加强筋） |
| 来料、巡检、全检、出货检验 | 问题出在哪个阶段，检过哪些项目，抽样覆盖够不够 | `inspections.json` |
| 批次追溯（材料批次 → 生产批次 → 出货批次） | 影响范围，有没有共同的材料、设备、时段 | `lots.json` |
| 工艺 / 设备记录、变更（4M 变更） | 出问题前后有没有变化，变化有没有走评审 | `process_records.json`、`lots.json` 的 changes |
| 包装、运输 | 是否运输损伤、包装是否改过 | `lots.json` 的 packaging |
| 历史异常和 8D | 以前怎么处理，措施是否验证过 | `cases.json` |

来源：[GPT 调研] 多家供应商质量手册（Nordic Lights、Gamesa Electric、Sumitronics）、[TI 失效分析流程](https://www.ti.com/quality-reliability/faqs/failure-analysis.html)。

## 3. 原因分类

- **鱼骨图六类**：人、机、料、法、测、环。分类本身不证明因果。[公开流程] [ASQ 鱼骨图](https://asq.org/quality-resources/fishbone)
- **发生原因 vs 流出原因**：8D 要求两类都查。
- **“非我方责任”不能由单一证据得出**：出货检验合格、检测未复现、有过应力损伤，都不足以单独免责；最终责任要双方确认。[GPT 调研 + 推理]

## 4. 时效（公开例子，不是全行业标准）

| 例子 | 要求 |
|---|---|
| Volvo Group（2025） | 48 小时完成遏制，10 个工作日完成原因分析和永久措施，20 个工作日检查有效性 [GPT 调研] |
| BSH（2021） | 2 天报遏制，14 天报原因分析，60 天纠正措施报告，90 天完成 8D [GPT 调研] |

**对“更快”的启示**：首次回复、初稿、原因确认、结案是不同节点。我们比的是“同一份资料 → 可供审核的调查初稿”的时间，不和几十天的结案周期比。

## 5. 缺陷词表（写合成数据和测检索用）[通用知识]

### 注塑件

| 缺陷 | 常见说法（同义词） | 典型发生原因 |
|---|---|---|
| 划伤 | 刮伤、刮痕、刮花、划痕、擦伤 | 包装 / 运输摩擦、模具毛刺、取件搬运 |
| 缩痕 | 凹陷、缩水、凹痕 | 模温低、保压不足、壁厚不均、冷却不良 |
| 飞边 | 毛边、披锋、批锋 | 锁模力不足、分型面磨损、注射压力过高 |
| 尺寸超差 | 孔位偏、装不进、尺寸不良 | 保压 / 收缩变化、模具磨损、测量方法不一致 |
| 开裂 | 断裂、裂纹 | 材料含水率高、内应力、熔接线弱 |
| 色差 | 偏黄、颜色不一致 | 色母批次、料温、回料比例 |
| 银纹 | 料花、水花 | 材料受潮、干燥不足 |
| 白斑 / 雾斑 | 白点、发白 | 脱模剂残留、材料污染、模具表面 |

### 显示模组

| 缺陷 | 常见说法 | 典型发生原因 |
|---|---|---|
| 划伤 | 细划痕、刮伤 | 搬送设备摩擦、治具、拆包操作 |
| 异物 | 黑点、小黑点、灰尘 | 贴合前清洗不足、环境洁净度 |
| 点缺陷 | 亮点、暗点、坏点 | 面板本身、静电、压伤 |
| 压痕 | 保护膜压痕 | 包装压力（撕膜后可能消失，容易误判） |

### 零件 / 部件的同义说法

外壳、壳体、外盖、底壳、上盖；模组、屏、显示屏。

## 6. 现有产品（区分点参考）[GPT 调研，厂商自述，未实测]

Babtec Quorix、ComplianceQuest、8D Reports 都已经有“AI 辅助写 8D / 检索历史 / 人工审批”的功能。所以“AI 写报告 + 检索 + 审批”本身不是创新；要在现场证明的是：引用受本次查到的资料约束、证据变了结论跟着变、证据不足时会停下来。
